# OutLier Lightsout v2

## Overview
OutLier Lightsout v2 is a comprehensive cursor theme featuring a main set of cursors plus a Bonus pack of additional pointer designs.

## Features
- 18 main cursor/ani files covering all standard cursor types
- Bonus pack with 12 additional pointer designs (aurora, blue-deep, blue-ice, blue-indigo, blue-sky, candy, gold, grape, lava, lime, mint, peach, rose, sunset)
- Standard cursor set: alternate, busy, diag1/2, help, horizontal, move, pen, person, pin, point, precise2, text, unavailable, vertical
- Main cursor file: ol_pointer.cur (default pointer)
- PDF documentation (EN.pdf, RU.pdf)
- Installation configuration (OutLier_install.inf)

## Main Cursor Set
- ol_alternate.cur, ol_busy.ani, ol_diag1.cur, ol_diag2.cur
- ol_help.cur, ol_horizontal.cur, ol_move.cur, ol_pen.cur
- ol_person.cur, ol_pin.cur, ol_point.cur, ol_pointer.cur
- ol_precise2.cur, ol_text.cur, ol_unavailable.cur, ol_vertical.cur
- ol_working.ani

## Bonus Pointer Designs (12 files)
- ol_pointer_aurora.cur, ol_pointer_blue-deep.cur, ol_pointer_blue-ice.cur
- ol_pointer_blue-indigo.cur, ol_pointer_blue-sky.cur, ol_pointer_candy.cur
- ol_pointer_gold.cur, ol_pointer_grape.cur, ol_pointer_lava.cur
- ol_pointer_lime.cur, ol_pointer_mint.cur, ol_pointer_peach.cur
- ol_pointer_rose.cur, ol_pointer_sunset.cur

## Files
- `OutLier_install.inf` - Windows installation script
- `EN.pdf` - English documentation
- `RU.pdf` - Russian documentation
- `source.url` - Source link
- `Bonus/` folder - Additional pointer designs (12.cur files)
- 18 main cursor/ani files in root directory

## Installation
Use the OutLier_install.inf file to install the cursor theme on Windows systems.
