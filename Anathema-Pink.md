# Anathema Pink Cursor Collection

![Preview](Preview.jpg)

## Overview
Anathema Pink is a comprehensive cursor theme featuring a complete set of cursor and mouse pointer animations in pink color scheme.

## Features
- 17 normal select cursors and animations
- Alternate, link, move, precision, text, handwriting, unavailable, vertical, horizontal, diagonal (2 versions), resize, and cursor variants
- Bonus cursors including Handwriting Version 2, Precision Select Thicker, and Text Select Static
- Full PDF documentation (EN.pdf, RU.pdf)
- Installation configuration (Installer.inf)

## Cursors Included
- Normal Select, Help Select, Working in Background, Busy
- Precision Select, Text Select, Handwriting, Unavailable
- Vertical Resize, Horizontal Resize, Diagonal Resize 1&2, Move
- Alternate Select, Link Select, Handwriting Version 2 (Bonus)
- Precision Select Thicker (Bonus), Text Select Static (Bonus)

## Installation
Use the Installer.inf file to install the cursor theme on Windows systems.

## Files
- `Preview.jpg` - Theme preview image
- `EN.pdf` - English documentation
- `RU.pdf` - Russian documentation  
- `Installer.inf` - Windows installation script
- 23 cursor/ani files in root (bonus cursors merged from subfolder)
