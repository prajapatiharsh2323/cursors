# Bibata Cursor

## Overview
Bibata Cursor is a modern SVG cursor theme with a clean, minimalist design.

## Features
- SVG cursor format for high-DPI displays
- Modern aesthetic with focus on readability
- Multiple cursor variants and configurations
- Build script included for rendering cursors
- Comprehensive changelog and configuration options

## Theme Structure
- SVG cursor files in `svg/modern/` directory
- Configuration files in `configs/` directory (normal, right variants)
- Build system with `build.sh` and `package.json`
- CHANGELOG and CODE_OF_CONDUCT included

## Available Cursors
- Standard arrow, crosshair, hand, text, and resize cursors
- Custom designed variants for different screen contexts
- Configurations for different display scenarios

## Installation
Follow the build script (`build.sh`) to render the SVG cursors to the desired format for your operating system.

## Files
- `README.md` - Main documentation and installation instructions
- `CHANGELOG.md` - History of changes and updates
- `build.sh` - Script to build/render the cursor theme
- `configs/` - Pre-configured setups for different scenarios
- `svg/` - SVG source files for all cursors
- `package.json` - Project dependencies and build configuration
- `pling.txt` - Publix link information
- `render.json` - Render configuration

## Notes
- SVG format ensures crisp rendering at any resolution
- Theme actively maintained with regular updates
- Multiple configuration options for different use cases
