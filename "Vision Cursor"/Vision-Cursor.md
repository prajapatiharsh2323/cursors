# Vision Cursor

## Overview
Vision Cursor is a cursor theme featuring CUR files and PNG icon assets in multiple color schemes.

## Features
- 17 cursor/ani files in CUR format
- PNG icons in multiple sizes (32px, 48px, 64px, 96px, 128px)
- Available in White color scheme with PNG assets for Pointer and Text cursors
- Installation configuration (.Install.inf)
- Preview image included

## Cursor Files (CUR format)
- pointer.cur, cross.cur, handwriting.cur, alternate.cur
- dgn1.cur, dgn2.cur, help.cur, busy.ani
- horz.cur, vert.cur, move.cur, person.cur
- pin.cur, text.cur, unavailiable.cur (note: spelled "unavailiable" in source)
- work.ani

## PNG Icon Assets
- Pointer icons: 32px, 48px, 64px, 96px, 128px
- Text icons: 32px, 48px, 64px, 96px, 128px

## Installation
Use the .Install.inf file in src/Vision-White/ to install the cursor theme on Windows systems.

## Files
- `src/Vision-White/CUR/` - CUR format cursor files
- `src/Vision-White/PNG/` - PNG icon assets (Pointer and Text subdirectories)
- `assets/preview.png` - Theme preview image
- `LICENSE` - License file
- `README.md` - Additional documentation
