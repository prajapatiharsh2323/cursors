## Overview
Cursor Concept 3 is a cursor theme available in both Light and Dark versions, created by JepriCreations. Each version includes 17 different cursor types for various Windows cursor functions.

## Features
- Available in both Light and Dark color schemes
- 17 cursor types per version: arrow, help, appstarting, wait, crosshair, nwpen, no, sizens, sizewe, sizenwse, sizens, sizeall, uparrow, hand, person, pin
- PDF documentation in English and Russian
- Installation configuration with registry entries
- No forced startup entries or invasive registry writes (cleaned up in organized version)

## Light Version Cursors
- arrow.cur, help.cur, appstarting.ani, wait.ani
- crosshair.cur, nwpen.cur, no.cur, sizens.cur
- sizewe.cur, sizenwse.cur, sizens.cur, sizeall.cur
- uparrow.cur, hand.cur, person.cur, pin.cur

## Dark Version Cursors
- Same 17 cursor types as Light version
- Identical structure with dark color adaptation

## Files
- `light/` folder - Light theme cursor files
- `dark/` folder - Dark theme cursor files
- `EN.pdf` - English documentation
- `RU.pdf` - Russian documentation
- `source.url` - Source link
- `Install.inf` - Installation script (both light and dark folders)

## Installation
Use the Install.inf file in each folder to install the cursor theme on Windows systems.
