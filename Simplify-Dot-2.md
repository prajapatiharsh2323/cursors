## Overview
Simplify Dot 2 is a cursor theme available in both Light and Dark versions, featuring a complete set of 17 cursor/ani files for various Windows cursor functions.

## Features
- Available in both Light and Dark color schemes
- 17 cursor types per version: normal select, help, working in background, busy, precision select, text select, handwriting, unavailable, vertical resize, horizontal resize, diagonal resize (2 versions), move, alternate select, link select, location select, person select
- Clean installation files without Scheme.Txt references (cleaned up in organized version)
- PDF documentation (EN.pdf, RU.pdf)
- Preview image (simplify_dot_2_cursors_preview.png)

## Light Version Cursors
- 01_normal_select.cur through 17_person_select.cur
- Covers: select, help, working, busy, precision, text, handwriting, unavailable, vertical, horizontal, diagonal (2), move, alternate, link, location, person

## Dark Version Cursors
- Same 17 cursor types as Light version
- Identical structure with dark color adaptation

## Files
- `Simplify Dot 2 Light/` folder - Light theme cursor files
- `Simplify Dot 2 Dark/` folder - Dark theme cursor files
- `simplify_dot_2_cursors_preview.png` - Theme preview image
- `EN.pdf` - English documentation
- `RU.pdf` - Russian documentation
- `source.url` - Source link
- `_install.inf` - Installation script (both light and dark folders)

## Installation
Use the _install.inf file in each folder (Light or Dark) to install the cursor theme on Windows systems.
